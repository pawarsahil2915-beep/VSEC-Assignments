6. Update One Document

db.students.updateOne(
    { name: "Harshal" },
    { $set: { marks: 90 } }
);

Output:

{
    acknowledged: true,
    matchedCount: 1,
    modifiedCount: 1,
    upsertedCount: 0
}

7. Update Multiple Documents

db.students.updateMany(
    { course: "CS" },
    { $set: { course: "Computer Science" } }
);

Output:

    matchedCount: 2,
    modifiedCount: 2,
    upsertedCount: 0
}

14. Drop Collection

The drop() method deletes an entire collection from the database.

Command:

db.students.drop();

Output:

true

15. Drop Database

The dropDatabase() method deletes the currently selected database.

Command:

db.dropDatabase();

Output:

{
    ok: 1,
    dropped: 'harshal'
}
